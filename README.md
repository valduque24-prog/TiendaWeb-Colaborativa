# Tienda Web Colaborativa

## Descripción

Proyecto colaborativo desarrollado como continuación del proyecto de la Semana 6 de la asignatura Programación Web II. La aplicación corresponde a una tienda de comercio electrónico desarrollada con PHP, MySQL, HTML, CSS y JavaScript, incorporando herramientas colaborativas de GitHub para el control de versiones y el trabajo en equipo.

## Funcionalidades actuales

- Registro de productos.
- Registro de clientes.
- Registro de compras.
- Actualización automática del stock.
- Validaciones en JavaScript.
- Validaciones en PHP.
- Consulta avanzada de compras.

## Tecnologías utilizadas

- MySQL
- HTML
- CSS
- JavaScript
- Git

## Ejecución del proyecto

1. Copiar la carpeta del proyecto dentro de `htdocs`.
2. Iniciar Apache y MySQL desde XAMPP.
3. Importar la base de datos `tienda.sql` mediante phpMyAdmin.
4. Acceder desde el navegador mediante:

```
http://localhost/TiendaWeb-Colaborativa/
```
